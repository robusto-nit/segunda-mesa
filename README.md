# Segunda Mesa

Plataforma web para que una cafetería avise a tiempo sus excedentes de alimentos al cierre y alguien que pueda aprovecharlos los reserve y los recoja. Proyecto del Taller de Hackathon (Reto 1: desperdicio de alimentos).

> **Estado:** en desarrollo. Este README se irá completando durante el semestre.

## Solución

Flujo mínimo previsto:

1. La cafetería registra un excedente (alimento, cantidad, unidad, horario).
2. La persona que recoge consulta lo disponible y reserva una cantidad.
3. El sistema actualiza la disponibilidad.
4. Se confirma lo recogido y se consulta el resumen.
