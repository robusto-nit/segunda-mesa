# Documentación del proyecto

Aquí guardamos la investigación y las decisiones del equipo.

Archivos sugeridos:

- `ficha-de-trabajo.md`: problema, usuario, evidencia, métrica y próxima acción.
- `investigacion/`: notas de entrevistas y observaciones (sin datos personales identificables).
- `alternativas.md`: alternativas comparadas y razones de elección o descarte.
- `fuentes.md`: fuentes con organización, título, enlace, periodo del dato y fecha de consulta.
- `plan-de-negocios.md`: análisis de viabilidad.
